# 🌐 Fundamentos de Arquitetura Web, HTTP, API REST, HTML, CSS e JavaScript

**Por [@karizeviecelli](https://github.com/karizeviecelli) · 2026**

Bem-vindo(a)! Este repositório reúne todo o material da unidade curricular **Fundamentos de Arquitetura Web, Protocolo HTTP, Conceitos de API REST, HTML, CSS e JavaScript**, do curso Técnico em Desenvolvimento de Sistemas.

Aqui você vai encontrar as aulas, atividades, gabaritos e o roteiro do seu projeto final.

---

## 📋 Sobre o curso

Esta unidade é o seu primeiro contato com o desenvolvimento web. A proposta é simples: você vai sair daqui entendendo **como a internet funciona por trás das telas** e sabendo **construir uma página web do zero**, com interface, estilo e interatividade — inclusive puxando dados reais de uma API.

- **Carga horária total:** 65 horas
- **Duração de cada aula:** 4 horas
- **Total de encontros:** 16 aulas + 1 encontro de apresentação final
- **Pré-requisitos:** nenhum. O curso é pensado para quem está começando agora.

---

## 🧭 Como o curso vai funcionar

As aulas seguem uma **metodologia ativa**: você vai programar muito mais do que ouvir teoria. Cada encontro segue este formato:

1. **Uma analogia do dia a dia** para você entender o conceito antes de ver o código (ex.: o protocolo HTTP explicado como um pedido em um restaurante).
2. **Conteúdo teórico curto**, com exemplos de código sempre comentados linha a linha.
3. **Atividade prática**, feita em aula, individualmente ou em dupla.
4. **Gabarito no final do arquivo**, para você conferir sua solução depois de tentar.

Cada aula é um arquivo `.md` neste repositório. No fim de cada atividade tem um botão `Ver Gabarito »` que leva direto à resolução comentada, e no gabarito tem um botão `« Voltar para a Atividade` para você retornar de onde parou.

> 💡 Dica: tente resolver a atividade sozinho(a) antes de olhar o gabarito. É assim que o aprendizado gruda.

## 🗺️ Trilha de aprendizado

O curso é dividido em blocos, na ordem em que você vai aprender:

### 1️⃣ Fundamentos de Arquitetura Web e HTTP (Aula 1)
Como a internet funciona, o que acontece quando você digita um endereço no navegador, e como cliente e servidor "conversam" através do protocolo HTTP.

### 2️⃣ HTML (Aulas 2-3)
A estrutura de toda página web. Você vai aprender a montar páginas com tags semânticas e formulários acessíveis.

### 3️⃣ CSS (Aulas 4-6)
A parte visual. Seletores, cores, box model, e como criar layouts modernos e responsivos com Flexbox e Grid.

### 4️⃣ JavaScript — Fundamentos (Aulas 7-10)
A lógica por trás da interatividade: variáveis, funções, manipulação do DOM e eventos (cliques, formulários, etc.).

### 5️⃣ JavaScript — Aprofundamento e API REST (Aulas 11-14)
Aqui o curso fecha o ciclo: você retoma o protocolo HTTP para entender **Conceitos de API REST** (o que é um endpoint, um recurso, o formato JSON) e aprende a usar `fetch` para consumir dados reais de uma API, com autenticação básica e tratamento de erros.

### 6️⃣ Projeto Final (Aulas 15-17)
Você constrói, do zero, um projeto que une tudo: HTML + CSS + JavaScript consumindo uma API REST. Nas duas últimas aulas você desenvolve e publica o projeto no GitHub, e no encontro final você o apresenta para a turma.

---

## 🎯 O que você vai saber fazer ao final

- Explicar como a Web funciona (cliente-servidor, DNS, hospedagem).
- Entender e testar requisições HTTP (métodos, status codes, headers).
- Consumir uma API REST e trabalhar com dados em JSON.
- Construir páginas com HTML semântico.
- Estilizar interfaces responsivas com CSS (Flexbox e Grid).
- Programar interatividade com JavaScript e manipular o DOM.
- Publicar um projeto completo no GitHub.

---

## 📁 Projeto Final

Ao longo do curso, você vai construindo um projeto próprio, com entregas parciais (checkpoints) nas aulas 3, 6, 10, 14 e 16. O projeto final precisa ter:

- Estrutura em HTML semântico.
- Estilização responsiva em CSS.
- Interatividade em JavaScript.
- Consumo de pelo menos uma API REST pública, via `fetch`.
- Código comentado, versionado no Git e publicado no GitHub.
